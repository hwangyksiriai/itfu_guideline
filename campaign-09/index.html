🧖 [촬영 배경] 사우나 · 반신욕 · 효소찜질 · 운동 중 택 1 (필수) ▾
  • 평소 루틴에 맞게 설정해 주세요 — 퇴근 후 사우나 / 러닝·산행 후 사우나 / 운동 후 사우나 / 쉬는 날 반신욕 / 효소찜질 등
  • 사우나·효소찜질은 내부 촬영이 가능하면 프라이빗 사우나 또는 찜질방에서 촬영해 주세요.
  • 운동 크리에이터는 러닝 · 등산 · 헬스 등 평소 운동 직후 루틴으로 진행해도 좋아요. 운동 현장, 귀가하는 차 안, 자택에서 촬영해 주세요.
  • 내부 촬영이 어렵다면 이용 후 차량이나 자택에서 촬영하는 것을 권장합니다.
  • 촬영 주의: 다른 이용객의 얼굴·신체가 노출되지 않도록 해주세요.
🎬 [스토리보드] 제품 삽입 흐름 (필수) ▾
0) 첫 장면 — 채널 톤에 맞게 하나 선택 (내용 자유)
  • 웰니스 연결: “내 삶을 사랑하는 법” / “퇴근 후 피로를 푸는 힐링 사우나”
  • 운동 연결: “러닝 끝나고 얼굴 터질 것 같은 날” / “운동 후 달아오른 얼굴, 이렇게 식혀요”
  • 비포 비주얼: 사우나류 후 열감 + 홍조 + 모공 늘어짐 클로즈업
  • 공감 카피: “사우나 후 피부 상태 어떡하지” / “피부 망가질까봐 사우나 못하는 사람! 저요~!” / “사우나 자주 하는 사람들 주목!” / “운동만 하면 얼굴 빨개지는 사람!”
  • 질문형: “사우나 한 날 · 운동 끝난 날 얼굴 이렇지 않아요?” → 바로 달아오른 얼굴 컷
  • 루틴·꿀팁 전수: “사우나 필수템 / 운동 가방 필수템 / 운동 후 스킨케어 루틴”
  • 제품 사용: 사우나 중 또는 운동 직후(라커룸 · 차 안) 패드를 붙이고 있거나 앰플을 바르는 장면
  • 브이로그: 사우나 · 운동 브이로그 속에서 자연스럽게 제품 노출·설명
※ ‘사우나류’ = 사우나 · 반신욕 · 효소찜질 통칭
※ 운동 크리에이터는 예시의 ‘사우나’를 ‘운동(러닝 · 등산 · 헬스 등)’으로 바꿔 적용해 주세요.
1) 고민 (후킹과 자연스럽게 연결 · 생략 가능)
사우나류 또는 운동(실제 진행) 후 홍조 · 열감 · 열린·늘어진 모공 · 푸석한 피부결 → “사우나 한 날 / 운동한 날 루틴”으로 연결
2) 쿨다운
사우나 · 운동 후 수딩 패드 3분 진정팩, 밀착 클로즈업
3) 모공 케어
순율 앰플 질감 클로즈업 → 두드려 흡수
4) 세트 소개 (2~3 진행하며 나레이션으로)
패드 = 열감·수분 / 앰플 = 모공·피부결
“무신사에서 유명한 브랜드 잇퓨” + 매장 사진 / 사우나 애프터케어 세트 판매 소개
5) 성분 · 수치
패드·앰플 핵심 성분과 수치를 자막과 함께 (아래 제품 특징 중 일부 선택)
6) 후기
1~2주 사용감 (비포/애프터 권장)
7) 마무리
세트 링크 · 할인코드 안내
✅ [필수 내용] 영상 내 포함 (필수) ▾
  • 영상에 ‘유료 광고’ 표시
  • 제품명 ‘잇퓨 히알루론산 카테킨 수딩 패드’, ‘잇퓨 스킨 리밸런싱 순율 앰플’ 정확히 언급
  • 밝은 곳에서 촬영한 제품 세트 단독 샷 포함
  • “무신사에서 유명한 브랜드 잇퓨” 언급 + 브랜드 제공 매장 사진 사용
    무신사 오프라인 매장 사진 받기 →
  • 사용 순서: 수딩 패드로 열감 먼저 진정 → 열기가 가라앉은 뒤 순율 앰플
  • (권장) 비포/애프터 사진을 넣어 쿨링 진정 + 모공 케어 느낌 강조
표현은 “열 오른 피부 진정 + 늘어진(열린) 모공 · 푸석푸석한 피부결 정돈” 방향으로 해주세요.
